# NekRS Hypervapotron Benchmark

This case is designed as a performance benchmark for the application of the NekRS spectral element method computational fluid dynamics code to a fusion-relevant problem, in this case the flow through a hypervapotron. These complex channels are periodic in nature, and as such this case uses periodic boundary conditions to resolve a single repeating unit of the geometry.
